# 版本记录

## v1.0.1 — 2026-09-12

修复两个构建入口：均为经典脚本自包含 HTML；移除 Import Map / data-URL 模块依赖。增加启动和无脚本诊断；顶部品牌点击不再使离线页面跳到父目录。新增 4 个构建测试及 11 个真实文件/HTTP 导航与错误处理场景；CI 已通过 14 个 Node 测试、18 个交互检查组和 11 个导航场景。旧版普通 index.html 的 file:// CORS 空白故障已复现，旧版 standalone 在对照环境能够启动。具体证据见 OPENING-AUDIT-20260912.md。

## v1.0.0 — 2026-09-12

初始交付：iPhone 17 Pro 三维展台；21 个 Apple 爆炸图装配项与 3 个说明性附加组；爆炸/组装、连续滑杆、独立网格、来源检索、隔离、分类显隐、转台与 PNG 输出；桌面/移动端布局；WebGL 2 与深度缓冲软件回退；无运行依赖静态构建和离线单文件构建。

校验覆盖几何、目录、法线、边界框、相机数学、射线拾取、点击/拖动区分和浏览器交互。具体结果及未验证环境以 TESTING.md 为准。

不包含 iPhone 18 Pro 模型、官方 CAD、全量 BOM、真实地区机型的完整校准、维修顺序或自动上线网站。
