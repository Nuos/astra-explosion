# 架构与建模约定

版本：1.0.0。实现机型：iPhone 17 Pro。

## 模块边界

`catalog.js` 管理部件身份、公开依据、名称、分类、初始位置和爆炸位移；不负责绘制。`geometry.js` 只消费该目录生成确定性三角形网格，不读取 DOM。`math.js` 不依赖 DOM，供几何、相机、拾取与测试共用。`renderer.js` 管理图形上下文、材质、纹理、事件与两种绘制路径。`main.js` 将 UI 状态与模型变换相连。修改外观不应改写证据状态，改变型号也不应沿用未经验证的几何。

## 几何与坐标

1 模型单位对应 20 mm。手机局部 X 向右、Y 向上、Z 指向显示屏；机壳名义中心为原点，展台展示时整体上移。每个可选组有稳定 `id`、边界框、所属网格与独立变换。目录 01–21 对应 Apple 爆炸图编号；A1–A3 明确标识为说明性附加组。相机中的多个镜头属于同一可选装配项，不被虚报成额外官方编号。

几何由圆角盒、空心框、圆柱、圆环和贴图平面组成。同一组内同材质网格合并，24 组选件合计 80 个手机网格批次。构造器跳过退化三角形；全部顶点带位置、法线和 UV。内部形状、厚度、排线和芯片布局是估计；外壳尺寸检验只约束名义包络，不把按钮及镜头凸起计入精确制造图。

## 状态与布局

`target` 是用户指定的分离程度，`amount` 是动画中的实际值。分层状态沿每个组的位移向量插值；没有将该顺序声称为安全拆卸顺序。Inventory 为当前可见组分配不重叠网格，按每个部件边界框独立缩放。手机窄屏下标签收缩为编号，完整解释在目录提供。

检索只改变目录结果；分类与显隐改变场景；隔离状态只显示所选组。退出隔离会恢复整体相机取景。快速切换目标从当前位置继续动画，不新建多个相互竞争的动画循环。系统的减少动画偏好可在运行期间切换。

## 绘制与拾取

首选 WebGL 2：显式顶点布局、深度测试、漫反射/高光近似材质，以及本地 Canvas 生成的纹理。不是光线追踪或摄影级材质仿真，也不声称真实金属反射、真实阴影或真实屏幕光学。

回退为 Canvas 2D 输出的 CPU 三角形光栅器，使用深度缓冲和透视修正 UV，而不是用一张预渲染图片伪装交互。软件回退限制绘制分辨率并保留选择与轨道相机；其速度、抗锯齿和 GPU 路径不同。

选择从屏幕点生成射线，变换到每组局部坐标，先做边界框粗检，再做逐三角形相交，取最近命中。点击检测独立于轨道控制：拖动超过阈值、第二个指针介入或取消事件都会阻止误选。

## 运行与交付

静态站点无外部运行依赖。构建器还以 Import Map + data 模块保留模块边界并输出单文件 HTML。开发服务器默认监听本机，不是带身份认证的公共生产服务器。HTTPS、内容安全策略、缓存与域名由实际部署平台负责；严格 CSP 的站点应部署模块版并配置相应策略。

`window.astra` 仅提供只读状态与部件屏幕投影诊断，方便复现交互测试，不包含文件、账号或网络写入接口。页面无遥测。PNG 输出仅导出展台画布，非整页 UI；带有示意模型说明。

## 后续验收边界

后续版本可加入实测 GPU 兼容性、经授权的更高精度资产、更多区域配置、无障碍审计、真实设备触控测试及新的文档充分支持的机型。不得把这些待办写成首版已完成能力。
